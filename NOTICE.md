# 📜 Aviso Legal y Atribución — ProjectJaina_ProjectJaina_IntiObjGPS

Este repositorio forma parte de las herramientas de Staff y desarrollo de **Project Jaina - Project Jaina**.
Contiene el editor y capturador de coordenadas GPS de GameObjects para World of Warcraft 3.3.5a (Build 12340).

---

## 2. Propósito Técnico
* Facilita a los Game Masters y constructores de mundo la captura rápida de orientación, cabeceo (pitch), alabeo (roll) y coordenadas cartesianas (X, Y, Z) para el spawn y colocación precisa de objetos en AzerothCore.
* Genera scripts SQL listos para inyección en la tabla `gameobject` de la base de datos de mundo.
